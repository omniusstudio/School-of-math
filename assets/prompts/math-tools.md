# Math Tool Visuals — AI Art Generation Prompts

> **Style Guide**: Math tools should be **clean, simple, and high-contrast**. Unlike the vibrant world art, these tools need to be visually clear so they don't distract from the math. Flat colors, minimal decoration, bold shapes. Transparent PNG.

## Chisanbop Hands

Two hands showing finger positions. Right hand = ones (fingers = 1 each, thumb = 5). Left hand = tens (fingers = 10 each, thumb = 50).

### Right Hand — All Fingers Down (showing 0)

```
2D cartoon right hand, palm facing viewer, all five fingers curled down into a fist, warm medium
skin tone, clean and simple design, designed for Chisanbop finger counting system, clear and
readable finger positions, clean black outlines, flat color with minimal shading, transparent
background, 256x256px
```

### Right Hand — Finger Positions

For the right hand, we need these value states:
- **0**: All down (fist)
- **1**: Index finger up, rest down
- **2**: Index + middle up, rest down
- **3**: Index + middle + ring up, rest down
- **4**: Index + middle + ring + pinky up, thumb down
- **5**: Thumb up only, all fingers down
- **6**: Thumb up + index up
- **7**: Thumb up + index + middle up
- **8**: Thumb up + index + middle + ring up
- **9**: All five up (thumb + all fingers)

**Prompt template for right hand:**

```
2D cartoon right hand, palm facing viewer, [FINGER POSITION DESCRIPTION], warm medium skin tone,
clean and simple, Chisanbop finger counting position showing value [N], clear readable finger
positions, clean black outlines, flat color, transparent background, 256x256px
```

**Total right hand positions: 10 (values 0-9)**

### Left Hand — Finger Positions

Same concept but for tens:
- **0 (0 tens)**: All down
- **10**: Index finger up only
- **20**: Index + middle up
- **30**: Index + middle + ring up
- **40**: Index + middle + ring + pinky up, thumb down
- **50**: Thumb up only
- **60**: Thumb + index up
- **70**: Thumb + index + middle up
- **80**: Thumb + index + middle + ring up
- **90**: All five up

**Prompt template for left hand:**

```
2D cartoon left hand, palm facing viewer, [FINGER POSITION DESCRIPTION], warm medium skin tone,
clean and simple, Chisanbop finger counting position showing value [N] tens, clear readable finger
positions, clean black outlines, flat color, transparent background, 256x256px
```

**Total left hand positions: 10 (values 0, 10, 20... 90)**

**Total Chisanbop hands: 20**
